Depot Thanit - ម៉ាស៊ីនគិតលុយ (Khmer sales calculator)

Files
- index.html : the whole app (HTML + CSS + JavaScript). No libraries needed.

Use
- Open index.html in any browser (phone or computer).

Host on GitHub Pages (free)
1. Create a new repository on GitHub.
2. Upload index.html to it.
3. Settings -> Pages -> Source: "Deploy from a branch" -> Branch: main -> Save.
4. After about a minute your link is https://YOURNAME.github.io/YOURREPO/
5. Share that link in Telegram.
